# PiperX 实时力矩仪表盘硬件验证记录（2026-08-11）

## 结论

本次验证证明了双 PiperX 从臂的只读 CAN 采集、力矩估计、SSE 推送、SSH
转发和本地浏览器显示链路可用，并且在观测窗口内没有增加 CAN 发送包或
接收丢包。它不构成绝对力矩精度证明，也未在无人现场看护的情况下主动启动
真实遥操运动。

当前两台从臂使用的旧标定只覆盖近似静态零跨度工作区。实机当前姿态超出该
范围时，估计器正确返回 `outside_calibrated_workspace`，网页把外力矩显示为
`--` 并断开曲线，而不是输出伪零值。开始绝对精度验收前，必须先在现有遥操
路径下采集覆盖目标姿态与速度范围的无接触动态标定。

- `/api/snapshot` 返回 `piperx-monitor-v1` 严格 JSON；
- `/stream` 依次返回 `ready` 和左右臂真实快照事件；
- Chromium 实际打开 1440×900 和 1280×720 页面，无控制台错误或警告；
- 左右臂切换、J1–J6 切换、暂停/继续、时间窗、旧固件警告和无效曲线断线均已检查。

真实快照中两臂均提供六维关节角、滤波角速度、原始电流、固定系数 effort、
模型力矩、偏置、温度和驱动状态。验证时未运行遥操，所以 `q_command` 的新鲜度
为 false；监控为严格只读且不主动查询固件，固件字段为 unknown。两项状态均
由网页明确显示，不用旧值冒充实时值。

## 仍需有人看护的动态验收

1. 从臂无接触，启动现有正常主从遥操，缓慢覆盖预计采集使用的姿态和速度，
   分别为左右臂记录至少 30–60 秒动态标定数据；不要由监控工具使能或运动机械臂。
2. 使用独立验证段检查无接触误差：静态 J2/J3 MAE 不高于 0.30 Nm、其他关节
   不高于 0.15 Nm，自由运动 p95 不高于 0.50 Nm。
3. 用已校准六维力传感器、拉力计或已知质量/力臂形成独立真值。至少选择正反
   两个方向和多个姿态，按 `tau_expected = J(q)^T F` 对齐比较；不能以
   effort 与估计值的相关性代替真值。
4. 同时打开网页并运行真实遥操，记录 EvoStudio 控制循环频率、can2/can3
   `rx_dropped` 增量和跟踪误差。若控制频率或跟踪质量下降，先降低 `--ui-rate`，
   不放宽估计器的数据有效性门限。
5. 只有动态无接触、已知载荷和遥操共存三项均通过，才开始另一个 EvoStudio
   数据集写入变更。
